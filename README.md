# Vamos Ler! 🦉

Jogo para aprender a ler em **português de Portugal** e em **inglês**, pensado para crianças a partir dos 5 anos.
A coruja Lia guia a criança por letras, sílabas, construção de palavras e leitura.

- Funciona no navegador, sem instalar nada. A voz da Lia é gravada (vozes neurais), por isso funciona em qualquer navegador.
- Pode ser instalado no telemóvel: no Chrome, menu ⋮ → **Adicionar ao ecrã principal** (ou **Instalar app**).
- Depois da primeira visita funciona **sem internet**.
- Não recolhe dados: o progresso fica guardado só no próprio dispositivo.

## Créditos das vozes
- Português: modelo "dii" de OpenVoiceOS — CC BY-NC-SA 4.0 (uso não comercial). https://huggingface.co/OpenVoiceOS/pipertts_pt-PT_dii
- Inglês: Kokoro-82M (voz "Isabella") — Apache 2.0. https://huggingface.co/hexgrad/Kokoro-82M
- Áudio gerado com sherpa-onnx (https://github.com/k2-fsa/sherpa-onnx).

Por causa da licença da voz portuguesa, este jogo é para uso gratuito e não comercial.
